Documentación de la API de Fixy.

Una API REST sobre HTTPS, con respuestas en JSON y autenticación por token. Conectá tu tienda o sistema para cotizar, generar guías, imprimir etiquetas, seguir envíos, gestionar stock y recibir cambios de estado por webhook.

⚠️ Referencia en construcción. Los ejemplos, URLs y nombres de campo de esta página son ilustrativos y están sujetos a validación del equipo técnico de Fixy. Para credenciales y la especificación definitiva, solicitá tu acceso.

Introducción

La API de Fixy te permite integrar tu operación de e-commerce de punta a punta: desde cotizar un envío en tu checkout hasta seguir el estado de cada guía en tiempo real, sin planillas ni tareas manuales.

REST / JSONEndpoints sobre HTTPS. Todas las respuestas en JSON, con códigos de estado HTTP estándar.
Token de accesoCada integración usa su propio token. Sin sesiones ni contraseñas en el código.
WebhooksRecibís los cambios de estado apenas ocurren. Sin polling ni consultas repetidas.

URL base

Base URL
https://api.fixy.com.ar/v2
Autenticación

Todas las llamadas requieren tu token de integración. Lo obtenés desde tu ejecutivo de cuenta o el portal de sellers. Podés enviarlo como header Authorization o como parámetro api_token.

curl — header
$ curl https://api.fixy.com.ar/v2/tracking/AR-1842.json \
  -H "Authorization: Token TU_TOKEN"

Mantené tu token del lado del servidor. No lo expongas en el frontend ni en repositorios públicos.

Versionado

La versión va en la ruta (/v1, /v2). Se mantiene la compatibilidad dentro de cada versión mayor; los cambios que rompen compatibilidad se publican bajo una versión nueva con aviso previo. Recomendamos usar siempre /v2.

POST/v2/cotizacion.json

Devuelve las opciones de envío disponibles y el tiempo estimado para un origen y destino. Ideal para mostrar opciones en el checkout.

Parámetros

CampoTipoDescripción
cp_origen requeridostringCódigo postal de origen.
cp_destino requeridostringCódigo postal de destino.
peso requeridonumberPeso del paquete en kilogramos.
volumen opcionalobjectAlto, ancho y largo en cm para peso volumétrico.
Request
$ curl -X POST https://api.fixy.com.ar/v2/cotizacion.json \
  -H "Authorization: Token TU_TOKEN" \
  -d '{ "cp_origen": "1414", "cp_destino": "5000", "peso": 1.2 }'
Response 200
[
  { "servicio": "NEXT_DAY", "entrega": "24-48h" },
  { "servicio": "SAME_DAY", "entrega": "en el día" }
]
POST/v2/guias.json

Genera una guía de envío. Devuelve el número de guía, su estado inicial y el enlace a la etiqueta.

Parámetros

CampoTipoDescripción
servicio requeridostringServicio a usar: NEXT_DAY, SAME_DAY, INTERIOR, etc.
destinatario requeridoobjectNombre, dirección, CP, teléfono y email del comprador.
bultos requeridoarrayDetalle de los paquetes (peso y dimensiones).
referencia opcionalstringTu ID de orden interno, para conciliar.
Request
$ curl -X POST https://api.fixy.com.ar/v2/guias.json \
  -H "Authorization: Token TU_TOKEN" \
  -d '{ "servicio": "NEXT_DAY", "cp": "1636", "referencia": "ORD-9021" }'
Response 201
{
  "guia": "AR-1842",
  "estado": "PENDIENTE_ARMADO",
  "etiqueta": "https://api.fixy.com.ar/v2/etiquetas/AR-1842.pdf",
  "referencia": "ORD-9021"
}
GET/v2/etiquetas/{guia}.pdf

Devuelve la etiqueta lista para imprimir de una guía. Disponible en PDF y en formato para impresoras térmicas (ZPL).

Request
$ curl https://api.fixy.com.ar/v2/etiquetas/AR-1842.pdf \
  -H "Authorization: Token TU_TOKEN" -o etiqueta.pdf
GET/v2/tracking/{guia}.json

Devuelve el estado actual de un envío, su historial de eventos y la estimación de entrega.

Request
$ curl https://api.fixy.com.ar/v2/tracking/AR-1842.json \
  -H "Authorization: Token TU_TOKEN"
Response 200
{
  "guia": "AR-1842",
  "estado": "EN_DISTRIBUCION",
  "eta": "hoy 14-18h",
  "historial": [
    { "estado": "EN_CAMINO", "ts": "2026-07-20T18:32:00-03:00" }
  ]
}
POST/v2/retiros.json

Solicita el retiro de paquetes en tu domicilio o depósito para una fecha y franja horaria.

Request
$ curl -X POST https://api.fixy.com.ar/v2/retiros.json \
  -H "Authorization: Token TU_TOKEN" \
  -d '{ "fecha": "2026-07-21", "franja": "AM", "guias": ["AR-1842"] }'
POST/v2/recepciones.json

Genera una recepción de mercadería para ingresar stock a Fixy Full (fulfillment). Devuelve el remito y el turno asignado.

Request
$ curl -X POST https://api.fixy.com.ar/v2/recepciones.json \
  -H "Authorization: Token TU_TOKEN" \
  -d '{ "items": [ { "sku": "REM-NEG-M", "cantidad": 50 } ] }'
GET/v2/stock?sku={sku}

Consulta el stock disponible y reservado de un SKU en Fixy Full.

Request
$ curl "https://api.fixy.com.ar/v2/stock?sku=REM-NEG-M" \
  -H "Authorization: Token TU_TOKEN"
Response 200
{ "sku": "REM-NEG-M", "disponible": 42, "reservado": 3 }
WEBHOOKPOST → tu endpoint

En lugar de consultar el estado repetidamente (polling), Fixy envía un POST a la URL que configures cada vez que una guía cambia de estado. Respondé con 200 para confirmar la recepción.

Payload que recibís
{
  "evento": "cambio_estado",
  "guia": "AR-1842",
  "estado": "ENTREGADO",
  "referencia": "ORD-9021",
  "pod": { "foto": true, "dni": true, "geo": true },
  "ts": "2026-07-20T19:07:00-03:00"
}

Cada webhook incluye una firma en el header para que verifiques que la llamada proviene de Fixy.

Estados de envío

El ciclo de vida típico de una guía. Los nombres finales de cada estado se confirman con el equipo técnico.

PENDIENTE_ARMADO EN_CAMINO EN_DISTRIBUCION ENTREGADO
NO_ENTREGADO REPROGRAMADO DEVUELTO
Errores

La API usa códigos de estado HTTP estándar. El cuerpo incluye un error con un mensaje descriptivo.

CódigoSignificado
200 / 201OK — la operación se completó.
400Solicitud inválida — falta un parámetro o el formato es incorrecto.
401Token ausente o inválido.
404Recurso no encontrado (por ej., guía inexistente).
422Datos válidos en forma pero no procesables (por ej., CP sin cobertura).
429Demasiadas solicitudes — superaste el límite de tasa.
500Error interno — reintentá o contactá a soporte.
Entorno de prueba

Antes de salir a producción, podés probar toda la integración contra un entorno de prueba con un token de sandbox: generás guías, disparás webhooks y validás tus respuestas sin afectar tu operación real. También publicamos una colección de Postman para acelerar los primeros llamados.
